Examples
========

The [plans/](plans/) directory contains real blueprints. This
directory contains additional blueprint example directories.

prose
-------

Link: [prose](prose/).

> For writing projects.

A barebones blueprint with:

* `blueprint.json`
* `skelton/`
* `tests/`

design
-------

Link: [design](design/).

> For graphic design projects.

A `scripts/` dir and a `blueprint.json` that demonstrates:

* System `"requirements"`
* CLI `"options"`
* `"setup"` steps
* `"after"` steps
